# Feedback from Thursday's review

1. **Tab title.** The browser tab just says "Document", which looks unfinished when people have a few tabs open. Please change the page title to "Tally".

2. **Bigger number.** On a phone the count is hard to read at arm's length. The count should be at least 48px.

3. **Negative counts.** Going below zero is allowed and that's fine, but people don't notice when it happens. When the count is negative, show the number in red (#c0392b). It should go back to the normal colour once it's zero or above again.

4. Add a Reset button to the counter.
